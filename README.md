# Fault-Tolerant Logical Gate Primitives via Dynamically Evolving Code Symmetries

This repository explores whether automorphisms of intermediate quantum error-correcting codes can be used to discover or simplify fault-tolerant logical gate constructions. The main case study uses the five-qubit `[[5,1,3]]` code and studies stabilizer-code automorphisms, embedded code constructions, pieceable fault-tolerant round-robin circuits, and extensions to CWS / hypergraph CWS descriptions for non-stabilizer intermediate codes.


**Code accompanying the 8.371 Quantum Information Science II final project**
